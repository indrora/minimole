# miniMOLE: the miniature Modular Output for Legacy Electronics.

the MiniMOLE is a tiny power supply for powering hard drives, floppy drives, etc. on the go. 

The power supplies that a lot of powerable HDD docks come with are just not good enough to handle some drives. Other times, you need something that doesn't fit in one of those docks. 

The miniMOLE is here for that: Either use a cablemod RT/Seasonic style modular peripheral cable or the included push-fit connectors for custom stuff. 

## fab notes:

* 2oz copper
* OSP or ENIG finish
* Everything has a JLCPCB part number.
